# Work-stream notes

One file per work stream: `ws1-boosting.md`, `ws2-app.md`, `ws3-backtest.md`,
`ws4-analysis.md`, `ws5-agents.md`. Start each with a half-page plan (goal,
first deliverable, data used, what is exploratory) and keep a short dated log of
decisions and results. These notes are working records; accepted decisions are
folded into `docs/DECISIONS.md` by the repository owner. See
[the group quick start](../GROUP_QUICKSTART.md) and
[the agent brief](../GROUP_AGENT_BRIEF.md).
